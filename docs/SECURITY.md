# אבטחה ומודל איום

CashWatch מחזיק בפרטי כניסה לחשבונות בנק, ולכן כאן מוסבר בכנות מה מוגן ומה לא.

## מה נשמר ואיפה

| מידע | איפה | הגנה |
|---|---|---|
| סיסמאות וסודות (בנקים, מייל, וואטסאפ, חתימת Webhook) | מסד נתונים מקומי (`data/`) | מוצפן AES-256-GCM |
| מפתח ההצפנה | ב-Windows: `.keyfile.dpapi` | עטוף ב-DPAPI, קשור למשתמש ה-Windows |
| מפתח ההצפנה (נעילה בסיסמה) | `.keyfile.pass` | עטוף בסיסמה שלך (scrypt + AES-256-GCM), לא נשמר במחשב |
| תנועות בנק ויתרות | מסד נתונים מקומי | **לא מוצפן** |
| פרופיל דפדפן ("מכשיר מהימן") | `data/browser-profiles` | כפי שהדפדפן מגן על עוגיות |
| טוקן API | גיבוב SHA-256 בלבד | הטוקן עצמו מוצג פעם אחת |

הסיסמאות לא חוזרות מה-API, מהדשבורד, מה-MCP ולא נכתבות ללוגים (יש בדיקות אוטומטיות על כך).

## ממה זה מגן

- העתקת קבצי התוכנה או תיקיית `data` למחשב או למשתמש אחר (ב-Windows).
- דליפת קובץ המסד לבדו (גיבוי, שיתוף בטעות).
- במצב נעילה בסיסמה: גם מי שמוצא את המחשב ונכנס ל-Windows לא יפענח את הסיסמאות בלי הסיסמה שלך.

## ממה זה לא מגן

- תוכנה זדונית שרצה תחת אותו משתמש ב-Windows: היא יכולה לבקש מ-DPAPI לפענח.
- מי שנכנס ל-Windows שלך כשלא הופעלה נעילה בסיסמה: התוכנה חייבת להיות מסוגלת לפתוח את הסיסמאות לבד כדי להתחבר בלי נוכחותך.
- חשיפת ה-API לרשת או לאינטרנט. הטוקן נותן קריאה לכל הנתונים הפיננסיים. אל תחשוף אותו; לגישה מרחוק מומלץ Tailscale ולא פתיחת פורטים.
- נתוני התנועות עצמם (ללא סיסמאות) אם הדיסק לא מוצפן.

## המלצות

1. סיסמה חזקה ל-Windows והצפנת דיסק (BitLocker / הצפנת מכשיר).
2. אם המחשב אבד: שנה סיסמאות בבנקים וברשימת "מכשירים מהימנים" שלהם.
3. שקול נעילה בסיסמה (הגדרות ← אבטחה) אם אינך סומך על הגנת המחשב בלבד. המחיר: הזנת סיסמה אחרי כל הפעלה, ושכחה = הזנה מחדש של פרטי הכניסה.
4. שמור את טוקן ה-API כמו סיסמה, ובטל אותו כשאינו בשימוש.

## דיווח על פגיעות

דווח בפרטיות (למשל דרך Security Advisories של הפרויקט ב-GitHub) ולא בכותרת Issue ציבורית.
